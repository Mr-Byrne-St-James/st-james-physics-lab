Rules for Algebraic Indices

Watch each solution build up line by line.

The three main index laws

Multiply → add
am × an = am+n
Divide → subtract
am ÷ an = am−n
Power of a power → multiply
(am)n = amn
These index laws only work directly when the BASE is the same.
× → ADD    ÷ → SUBTRACT    power of a power → MULTIPLY
